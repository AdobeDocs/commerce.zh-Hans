# 关于Commerce信息中心

Commerce信息中心是Adobe Commerce文档生态系统的跨产品入口点。 使用它可以在Adobe Commerce、[!DNL Adobe Commerce Optimizer]、[!DNL Adobe Commerce as a Cloud Service]和相关的Commerce服务中查找正确的产品、实施指导和体系结构推荐，而无需搜索多个文档站点。

有关每个产品的权威深入文档会继续存在于其自己的指南中。 信息中心策划并链接到相关内容，以便您能够从一个位置开始更快地到达正确的目标。

## 快速入门

| 部分 | 使用它可以 |
| ------- | --------- |
| [由角色开始](get-started/get-started-by-role.md) | 根据您的角色（业务从业人员、推销员、管理员、开发人员、解决方案架构师或合作伙伴）找到起点。 |
| [平台和服务](portfolio/platform-and-services.md) | 了解Adobe Commerce产品组合，并确定哪些产品和服务符合您的要求。 |
| [选择Commerce选项](portfolio/choose-commerce-option.md) | 获取有关根据您的部署偏好、操作要求和期望的基础架构管理级别选择正确的Commerce产品的指导。 |
| [店面](storefronts/overview.md) | 了解Adobe Commerce中可用的各种店面选项。 |
| Commerce的[AEM Assets集成](aem-assets/aem-assets-integration.md) | 将集中式数字资产管理添加到任何Commerce或Optimizer架构。 |
| [API](apis/commerce-apis.md) | 探索在Commerce Foundation、Storefront Services和Commerce Optimizer中使用的API系列。 |
| [实施指南](implementation-guides/overview.md) | 遵循通用实施历程（如构建店面或连接Commerce服务）的跨产品指南。 |
| [架构选项](architecture-options/overview.md) | 比较支持的Commerce体系结构并查看跨多个Commerce产品的参考模式。 |
| [见解和指南](guidance-and-insights/overview.md) | 在提供战略指导（包括白皮书、安全建议和最佳实践）时对其进行查找。 |
| [迁移和采用](migration-adoption/overview.md) | 规划在体系结构之间迁移或分阶段采用Adobe Commerce Optimizer。 |

>[!NOTE]
>
>Commerce信息中心不会替换产品文档。 有关分步配置和参考资料，请访问各个部分中的链接，了解权威产品指南。
