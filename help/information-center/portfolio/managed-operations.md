# 具有托管操作的[!DNL Adobe Commerce as a Cloud Service]

**启动速度更快，运行更有信心。**

[!DNL Adobe Commerce as a Cloud Service]是一个完全托管、无版本的SaaS平台。 Adobe可托管、扩展、保护和更新核心应用程序和基础架构，因此您的团队可以专注于构建出色的购物体验。

具有托管操作&#x200B;**的**[!DNL Adobe Commerce as a Cloud Service]&#x200B;是一款高级产品，它将平台与专门的Adobe Managed Services团队和指定的客户成功工程师(CSE)进行配对。 他们一起监控、指导和优化您的完整商业解决方案，包括您的[!DNL App Builder]应用程序、集成和由[!DNL Edge Delivery Services]提供支持的[!DNL Commerce Storefront]，从上线到启动和持续操作。

## 客户成功工程师

您指定的CSE是您在Adobe的单点联系人，也是整个[!DNL Adobe Commerce as a Cloud Service]工具集（包括由[!DNL Edge Delivery Services]提供支持的[!DNL App Builder]、[!DNL API Mesh]和[!DNL Commerce Storefront]）的专家。 您的CSE将与您和实施合作伙伴合作，以：

- 指导和支持您完成载入流程
- 管理配置和平台设置
- 建议集成和自定义的架构原则，包括由[!DNL Edge Delivery Services]提供支持的[!DNL App Builder]应用程序和[!DNL Commerce Storefront]
- 支持[!DNL Adobe Commerce as a Cloud Service]更新过程
- 通过规划、执行和监控提供事件支持
- 通过里程碑核对清单和专用上线战室协调您的上线工作
- 创建和维护特定于设置的Runbook
- 定期运行运行状况和优化评估，并提出建议

>[!NOTE]
>
>您的CSE提供指导和咨询服务。 您（或您的实施合作伙伴）仍负责开发和维护您的自定义项。 请参阅[共享责任安全和操作模型](/help/cloud-service/security/shared-responsibility.md)。

## 主动监控和事件响应

Managed Services团队会全天候监控您的完整解决方案（不仅仅是平台），以便在问题影响购物者之前对其进行解决：

- **性能监控** — 持续跟踪页面加载时间、响应时间和可用性。
- **流量监视** — 分析流量模式以检测可能指示问题、威胁或容量需求的尖峰或异常行为。
- **自动警报** — 通过CSE的主动外联，针对性能下降、停机或安全事件发出警报。
- **增强的响应** — 加快首次响应和解决的时间，在优先事件期间定期进行更新，并对符合条件的事故进行根本原因分析。

## 安全性

[!DNL Adobe Commerce as a Cloud Service]保护平台、基础架构和核心应用程序的安全。 通过托管操作，您还可以获得：

- **主动安全指导** — 专家指导，确保您进程外的自定义项的安全和合规性。
- **Web应用程序防火墙(WAF)优化和报告** — 针对超出标准全局规则集的流量调整的规则，包含有关阻止内容的定期报告。
- **高级速率限制** — 针对体积型攻击的额外保护。
- **安全审核和风险评估** — 定期审查漏洞并制定缓解计划。
- **事件响应** — 安全事件的即时行动计划，以最大程度地减少影响和停机时间。
