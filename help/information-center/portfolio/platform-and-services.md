# 探索Adobe Commerce平台和服务

无论您是需要完整的Commerce平台、选择如何托管和操作该平台，还是希望将店面和目录功能与现有的Commerce后端结合使用，Adobe Commerce都能根据您的需求提供选项。 在人类主导和代理的购物历程中，Adobe Commerce通过AI支持的产品发现、快如闪电的店面和单击结账，帮助品牌提高转化率和平均订单价值。 此概述将比较核心产品/服务并介绍用于扩展这些产品/服务的服务和开发人员工具，帮助您确定起点并确定哪些功能适合您的实施。

每种服务提供的服务各不相同。 在规划实施时，请查看有关特定产品和部署模型的文档。

## Commerce产品

### B2C和B2B商务

Adobe Commerce支持B2C和B2B业务模型，包括单个Commerce实例上的两个模型。 [Adobe Commerce B2B简介](https://experienceleague.adobe.com/zh-hans/docs/commerce-admin/b2b/introduction)

B2B功能因产品而异。 对于云基础架构和内部部署上的Adobe Commerce，Adobe Commerce B2B是一种扩展，它需要单独的许可证和安装。 Adobe Commerce as a Cloud Service包含核心B2B功能，例如默认的公司管理和报价。 请参阅[Adobe Commerce B2B](https://experienceleague.adobe.com/zh-hans/docs/commerce-admin/start/resources/extensions)。

### Adobe Commerce as a Cloud Service

Adobe Commerce as a Cloud Service是一款完全托管的云原生软件即服务(SaaS)产品。 Adobe管理核心Commerce应用程序、基础架构和更新。 其组件包括Commerce foundation、由Edge Delivery Services提供支持的Commerce Storefront、促销服务、产品视觉效果和开发人员工具。

请参阅[Adobe Commerce as a Cloud Service概述](https://experienceleague.adobe.com/zh-hans/docs/commerce/cloud-service/overview)。

### Adobe Commerce Optimizer

Adobe Commerce Optimizer是一款SaaS解决方案，用于改进店面、目录、产品发现和促销体验。 它可以与现有的Adobe Commerce或第三方商业后端配合使用，使组织能够实现客户体验的现代化，而无需更换管理交易的系统。

Adobe Commerce Optimizer可以从第三方来源摄取目录数据。 与第三方系统的购物车和结账集成使用API Mesh和App Builder等集成工具。

查看[什么是Adobe Commerce Optimizer？](https://experienceleague.adobe.com/zh-hans/docs/commerce/optimizer/overview)。

>[!NOTE]
>
>Adobe Commerce as a Cloud Service和Adobe Commerce Optimizer当前未相互集成。 在规划实施时，将它们视为单独的体系结构选项。

### Adobe Commerce内部部署

Adobe Commerce本地由商家或其托管提供商托管。 商家或提供商管理托管环境、基础设施和平台服务。

请参阅[内部部署安装概述](https://experienceleague.adobe.com/zh-hans/docs/commerce-operations/installation-guide/overview)。

### 云基础架构上的Adobe Commerce

云基础架构上的Adobe Commerce是一种platform as a service (PaaS)部署。 Adobe管理托管平台，而商家则负责应用程序级别的维护、自定义代码、配置和其他共享责任任务。

请参阅云基础架构上的[Commerce](https://experienceleague.adobe.com/zh-hans/docs/commerce-on-cloud/user-guide/overview)和[迁移到Adobe Commerce as a Cloud Service](https://experienceleague.adobe.com/zh-hans/docs/commerce/cloud-service/migration/overview)。

## 扩展Commerce的服务

### 店面与商品销售服务

店面和产品体验的Adobe Commerce服务包括：

- 由Edge Delivery Services提供支持的&#x200B;**[Commerce店面](https://experienceleague.adobe.com/en/tools/commerce-storefront/merchants/quick-start/create-content/)** — 用于构建面向客户的商务体验的店面选项。
- **[Storefront Services](/help/landing/home.md)** — 为Adobe Commerce（包括[!DNL Adobe Commerce on cloud infrastructure]和[!DNL Adobe Commerce as a Cloud Service]）提供云端交付的SaaS功能，这些功能支持店面API和服务，以实现优化的目录访问、AI驱动的搜索和产品推荐，以及支付处理，从而帮助商家改善购物体验、性能和转化
  - 目录服务 — 支持优化的产品目录体验和店面性能。
  - 实时搜索 — 提供AI支持的产品搜索。
  - 产品推荐 — 根据购物者行为、趋势和产品相似性提供推荐。
- **[Commerce Optimizer促销服务](/help/optimizer/overview.md)** — 为Commerce on Cloud和Adobe Commerce as a Cloud Service提供的云交付的API优先功能，这些功能使用目录数据和AI来改进产品发现 — 通过优化的目录访问、相关的搜索结果和个性化的产品推荐 — 帮助购物者查找产品并支持更好的店面性能和转化。
  - **产品可视化图表** — 通过Adobe Experience Manager Assets集成支持产品图像和媒体。

### 支付

**付款服务**&#x200B;提供付款方法和付款处理、订单和发票视图。 可用性取决于Commerce产品和部署。

请参阅[付款服务](https://experienceleague.adobe.com/zh-hans/docs/commerce/payment-services/guide-overview)。

### 数据和集成服务

Commerce包括用于连接平台和同步数据的服务和工具：

- **[Commerce服务连接器](/help/landing/saas.md)** — 将云端、内部部署或Magento Open Source上的Adobe Commerce连接到支持的Commerce SaaS服务。
- **[SaaS数据导出](/help/data-export/overview.md)** — 支持所连接服务的Commerce数据的移动和同步。
- **[数据连接](/help/data-connection/overview.md)** — 将Commerce数据连接到Adobe Experience Platform。
- **[Adobe Commerce Optimizer Connector](/help/aco-connector/overview.md)** — 将目录和定价数据从支持的Adobe Commerce部署同步到Adobe Commerce Optimizer。
- **[平台特定的连接器](/help/optimizer/integrations/integrations-overview.md#commerce-salesforce-connector)** — 在支持的情况下，将Adobe Commerce Optimizer与特定的第三方商务平台连接。

### 开发人员工具和可扩展性

开发人员功能包括&#x200B;**Adobe Developer App Builder**、**API Mesh**、**活动**、**Webhooks**&#x200B;和&#x200B;**管理UI SDK**。 这些工具支持自定义应用程序、集成和扩展。 可用性因Commerce产品而异。

请参阅[Adobe Commerce开发人员文档](https://developer.adobe.com/commerce/docs/)。
