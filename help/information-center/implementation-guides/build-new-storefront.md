# 新建店面

具有以下部署类型的Adobe Commerce客户可以使用Edge Delivery Services、Commerce插件组件和内容块构建新店面。

- Adobe Commerce as a Cloud Service
- Adobe Commerce Optimizer
- 使用不带Adobe Commerce Optimizer的Storefront Services在云或内部部署Adobe Commerce
- 使用Adobe Commerce Optimizer Connector的云上或内部部署Adobe Commerce

使用Adobe Commerce样板提供了一个有效的店面，您可以对其进行自定义并连接到您自己的Adobe Commerce或[!DNL Adobe Commerce Optimizer]实例。

>[!NOTE]
>
>对于云基础架构或内部部署的Adobe Commerce，通过连接器采用Adobe Commerce Optimizer是一个店面现代化选项，而不是要求。 如果选择此路径，请使用[Luma Bridge](https://experienceleague.adobe.com/en/tools/commerce-storefront/setup/discovery/luma-bridge/)将您的Luma店面与Edge Delivery Services店面连接。

## 快速入门

1. 查看[Adobe Commerce店面概述](https://experienceleague.adobe.com/en/tools/commerce-storefront/merchants/quick-start/create-content/)和[店面架构](https://experienceleague.adobe.com/en/tools/commerce-storefront/get-started/architecture/)文档，了解架构和可用的下拉组件。

1. 要设置店面，请遵循店面文档：

   - [创建店面](https://experienceleague.adobe.com/en/tools/commerce-storefront/get-started/create-storefront/)
   - [Storefront开发人员指南](https://experienceleague.adobe.com/en/tools/commerce-storefront/get-started/)来确定、设置和启动项目。

1. 将店面连接到Commerce后端。

   根据您的部署模型，按照说明操作。 有关详细信息，请参阅&#x200B;_店面开发人员指南_&#x200B;中的[后端选项](https://experienceleague.adobe.com/en/tools/commerce-storefront/get-started/backends/){target="_blank"}。
