# 将Adobe Commerce连接到AEM Assets以进行资源管理

AEM Assets可以通过不同的集成路径连接到Adobe Commerce，具体取决于Commerce产品。

对于云基础架构上的Adobe Commerce，请使用适用于Commerce的AEM Assets集成。 对于Adobe Commerce as a Cloud Service和Adobe Commerce Optimizer，请使用由AEM Assets提供支持的产品可视化图表。

>[!NOTE]
>
>本指南介绍了Adobe Commerce在云基础架构、Adobe Commerce as a Cloud Service和Adobe Commerce Optimizer上的AEM Assets集成路径。 遵循与您的产品和部署匹配的路径。

## 快速入门

1. 查看[AEM Assets与Commerce的集成](/help/aem-assets-integration/overview.md)文档，了解先决条件和设置。


1. 要通过AEM Assets启用资源管理，请按照&#x200B;_[适用于Commerce的AEM Assets集成指南](/help/aem-assets-integration/overview.md)_&#x200B;中针对您的部署类型执行的[后续步骤](/help/aem-assets-integration/overview.md#next-steps)说明。
